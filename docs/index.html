What Proofmark does

Works where you write

Gmail, Outlook, WhatsApp, Slack, Discord, Teams, search boxes and forms in your browser, plus desktop apps like WhatsApp, Outlook, Notepad, Word and the Claude app on Windows.

Instant checks, offline

Spelling, grammar, repeated words, all-caps and style checks run on your computer as you type. No account and no setup.

Free AI rewrites

Optional Deep check and Rewrite (concise, formal, friendly, confident) using Chrome's built-in AI, Ollama, LM Studio, LanguageTool or free cloud tiers, or your own Claude API key.

Private by default

Your text only leaves your computer if you choose a cloud AI engine, and only when you ask for a deep check or rewrite.

Install the browser extension

  1. Download proofmark-extension.zip and unzip it. Keep the proofmark-extension folder somewhere permanent, like Documents.
  2. Open chrome://extensions (or edge://extensions in Edge).
  3. Turn on Developer mode.
  4. Click Load unpacked and choose the proofmark-extension folder.
  5. Pin Proofmark from the puzzle-piece menu, refresh your open tabs and start typing.

Install the Windows app

  1. Download Proofmark-Desktop-win-x64.zip, right-click it and choose Extract All….
  2. Open the Proofmark-Desktop folder and double-click ProofmarkDesktop.exe. No .NET install is needed.
  3. If Windows shows “Windows protected your PC”, click More info → Run anyway (the app isn't code-signed).
  4. Proofmark appears in the system tray. Click into any text box and start typing.

Full instructions, free AI setup and troubleshooting are in the README on GitHub.
